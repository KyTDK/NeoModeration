# NeoModeration 1.4.0 — Marketplace Discovery Audit

**Captured:** 2026-07-24 (UTC). **Version:** 1.4.0.
**Purpose:** one honest, timestamped baseline of where NeoModeration is discoverable, so
we can measure whether the discovery work actually moves installs. Every figure below is
read from a public URL or public API — no private analytics.

> Marketplace **downloads** (someone fetched the jar) and bStats **active servers**
> (a running server that pinged home) are different signals and are never summed. A
> download is intent; an active server is real usage.

## Read of the baseline

- **Discovery is the bottleneck, not the product.** The plugin is invisible on Modrinth —
  the marketplace most Minecraft admins actually search — because it was never published
  there. That single 404 is the biggest fixable gap.
- **Trust signal is empty.** 0 ratings on Spigot, 0 stars on Hangar. Zero social proof for
  a first-time visitor deciding whether to try it.
- **Real usage is tiny but non-zero.** bStats shows 1 active server. 22 Spigot downloads
  with 1 active server implies people try and don't keep it running — a conversion/activation
  gap once discovery is fixed.

## Reusable audit command (credential-free, read-only)

```bash
echo "SpigotMC:"; curl -fsS "https://api.spiget.org/v2/resources/136721" \
  | python3 -c "import sys,json;d=json.load(sys.stdin);print(' downloads',d.get('downloads'),'rating',d.get('rating',{}).get('average'),'count',d.get('rating',{}).get('count'))"
echo "Hangar:"; curl -fsS "https://hangar.papermc.io/api/v1/projects/KyTDK/NeoModeration" \
  | python3 -c "import sys,json;s=json.load(sys.stdin).get('stats',{});print(' views',s.get('views'),'downloads',s.get('downloads'),'stars',s.get('stars'))"
echo "Modrinth:"; curl -s -o /dev/null -w " project HTTP %{http_code}\n" "https://api.modrinth.com/v2/project/neomoderation"
echo "bStats servers (latest):"; curl -fsS "https://bstats.org/api/v1/plugins/32542/charts/servers/data?maxElements=1"
```

## Decision gates (first 30 days after Modrinth publish)

- Discovery: ≥ 100 combined listing views.
- Install conversion: combined downloads / combined views ≥ 5% (where views exist).
- Activation: bStats active servers ≥ 3.
- Trust: ≥ 1 organic rating/review.
- Cloud-upgrade: ≥ 1 NeoModeration NeoMechanical API key used after 2026-07-24.

These are learning thresholds, not claims of product-market fit.
