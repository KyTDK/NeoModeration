## New competitive findings

1. **A bring-your-own-LLM-key class is emerging.** PixelChatGuardian pipes chat
   through Groq (`llama-3.1-8b-instant`) with the server owner's free API key,
   and ships a strike system, censor/block/silence actions, and 8+ languages.
   Implication: generic "AI moderation" is commoditizing. NeoModeration's edge
   must stay: purpose-built moderation API with visible quotas (`/nmod usage`),
   `no_store`/no-training privacy, fail-open/fail-closed + circuit breaker,
   monitor mode, and map-art. Strike/censor/multilingual are table stakes we
   still lack.
2. **ChatFilter confirms the coverage checklist.** Its feature set — chat,
   books, signs, commands, anvils; repeat/similar-message, caps, and
   character-spam filters; unicode filtering against hacked clients; word/IP
   whitelists; player-name exemption; staff alerts; per-surface bypass
   permissions — is exactly the daily-usefulness bar at ~2.2k downloads.
3. **Per-word exceptions are now expected** (Censura markets them explicitly);
   our `/nmod allow` shipped at the right time.
4. **Config complexity is the recurring complaint** against the big suites
   (ChatControl reviews). Every 1.4.0 feature must stay inside the
   ten-minute-setup promise: sensible defaults, presets updated to cover new
   features, `/nmod doctor` aware of them.

## 1.4.0 "Coverage" — locked scope

Everything runs locally first (free, fast) so cloud spend only goes to what
local rules can't judge.

### P0

1. **Local anti-spam module** (`moderation.spam.*`): message rate, duplicate/
   near-duplicate detection, caps percentage, character flood, command spam.
   Monitor-mode aware; player-name exemption in the caps filter; exempt
   permission `neomoderation.bypass.spam`.
2. **Censor action** (`type: CENSOR`): replace matched local words with `****`
   and let the remainder through; cloud/high-severity detections stay
   block-only by default.
3. **Progressive enforcement**: per-player strike counter with decay
   (`moderation.strikes.*`), escalation ladder (e.g. 1st: censor/warn, 3rd:
   mute, 5th: kick), shown in staff alerts ("strike 3/5").
4. **More surfaces via one shared pipeline**: signs, books/anvil renames, and
   configurable command arguments (`/msg`, `/tell`, ...) all feed the existing
   detection path with a `surface` tag; each surface can be off / monitor /
   censor / block. Per-surface bypass permissions.
5. **Local case history**: SQLite log (player, surface, reason, action, time,
   decision source), `/nmod cases [player]`, `/nmod case <id>`; raw-content
   retention explicitly configurable (default: store a redacted preview only).

### P1

6. `/nmod allow last` — one-command false-positive fix straight from a staff alert.
7. Unicode/hacked-client character filter (ChatFilter parity).
8. Discord webhook for alerts (respects `alerts.includeMessage` redaction).
9. bStats custom charts: mode distribution, cloud on/off, preset usage
   (aggregate only, no content).

### Distribution (blocked on owner accounts — carry-over P0)

- Modrinth + Hangar listings under the same identity/version.
- Screenshots: new sectioned `/nmod help`, a monitor alert, `/nmod test`,
  `/nmod doctor` — plus a 60-second setup video.
- Ask early adopters for Spigot reviews once cases/strikes ship (0 ratings is
  currently the biggest conversion blocker at 18 downloads).

## Out of scope (unchanged)

Chat formatting/channels/nicknames, GUI before commands are excellent,
mandatory external databases, embedded local LLMs, opaque telemetry.
